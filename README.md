# LeiloesTDSat

Sistema desktop para gestão e cadastro de leilões e produtos, desenvolvido em Java com interface gráfica e integração com banco de dados MySQL.

## Do que se trata o projeto
O projeto é um sistema criado para casas de leilão, permitindo o cadastro de novos produtos, listagem de itens cadastrados e persistência dos dados no banco de dados local.

## Tecnologias Utilizadas
- **Linguagem:** Java (JDK 8+)
- **Interface Gráfica:** Java Swing (NetBeans)
- **Banco de Dados:** MySQL
- **Driver de Conexão:** JDBC (mysql-connector-java-5.1.47)
- **Controle de Versão:** Git e GitHub
